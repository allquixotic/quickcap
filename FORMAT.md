# SPEC.md format

Sections: §G GOAL, §C CONSTRAINTS, §I INTERFACES, §V INVARIANTS,
§T TASKS, §B BUGS. Stable V/T/B identifiers; concise, testable statements.
Task columns: id | status (`.` pending, `~` active, `x` verified) | task | cites.
Bug columns: id | date | cause | fix. Only spec workflow edits requirements;
build workflow may advance task status after verification.
